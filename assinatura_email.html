Como usar

    
    
      
  1. Gmail: Configuracoes → Ver todas as configuracoes → Geral → Assinatura → Criar nova → Colar com Ctrl+Shift+V (sem formatacao) — ou abrir a assinatura no navegador, selecionar tudo e colar direto no campo
    2. 
      
  2. Outlook: Arquivo → Opcoes → Email → Assinaturas → Nova → Colar o HTML diretamente no editor
    3. 
      
  3. Apple Mail: Preferencias → Assinaturas → Criar nova → Abrir esta pagina no navegador → Selecionar a assinatura → Copiar → Colar no campo da assinatura
    4. 
      
  4. Dica universal: Abra esta pagina no navegador, selecione visualmente a assinatura no preview acima e arraste/copie para o campo de assinatura do seu cliente de e-mail
    5.
